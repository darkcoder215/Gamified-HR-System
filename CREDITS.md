# Asset Credits

The pixel-art world currently uses open-licensed (CC0 / CC-BY-SA) assets so the
game looks professional immediately. These are **placeholder/CC0 assets** and can
be swapped for a premium pack (e.g. LimeZu "Modern Exteriors/Interiors") later —
the loader is asset-agnostic (`src/game/gameConfig.ts` → `TILEMAP` / `PLAYER`).

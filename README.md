# رحلة التطوّر — منصّة باور لتطوير الموظفين

منصّة تفاعلية مُمتعة (gamified) لتطوير الموظفين وتقييم مهاراتهم وترقيتهم، بأسلوب لعبة RPG ثنائية الأبعاد ولوحات تحكّم فاخرة بهوية **باور**. واجهة عربية بالكامل (RTL)، وحركات سلسة، وأداء سريع، وجاهزة للنشر على Vercel.

A gamified HR employee improvement, assessment, and promotion system. It blends a pixel-art RPG overworld (a walking character + interactive stations) with luxurious POWR-branded dashboards. Fully Arabic / RTL, highly animated, front-end only (mock data + `localStorage`).

## التشغيل المحلي

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # فحص الأنواع + بناء الإنتاج إلى dist/
npm run preview   # معاينة نسخة الإنتاج
```

## طريقة اللعب

- تحرّك بمفاتيح **الأسهم** أو **WASD** (وعلى الجوال: عصا التحكّم الافتراضية).
- اقترب من إحدى المحطّات الأربع واضغط **E** أو زر التفاعل لفتح لوحتها:
  - ⚔️ **ساحة التقييم** — نزالات أسئلة معرفية تمنح الخبرة وتستهلك الطاقة عند الخطأ.
  - 📋 **لوحة المهام** — مهام تطويرية متعددة الخطوات تمنح خبرة وأوسمة.
  - 🏯 **برج الترقيات** — المسار المهني وعتبات الترقية مع تدفّق موافقة المدير.
  - 🏆 **قاعة الصدارة** — ترتيبك بين زملائك ومجموعة أوسمتك.
  - 🏢 **المقر — الهيكل التنظيمي** — فريق الشركة بالشخصيات وموقعك الحالي فيه.

### عناصر إضافية
- **خريطة مصغّرة (Mini-map)** أسفل اليمين تُظهر موقعك والمحطّات.
- **دليل بداية (Onboarding)** أسفل اليسار: قائمة مهام تفاعلية ترشد المستخدم الجديد.
- **الدليل (Guide):** تبويب يشرح كل مبنى ووظيفته وكيف يستفيد المستخدم + طريقة اللعب.
- **تحليلاتي (Analytics):** لوحة تُظهر أين يقف المستخدم (رادار مهارات، إحصاءات، تقدّم الترقية)
  مع توصيات ديناميكية «كيف تتقدّم من هنا».
- **برج الترقيات المُحسّن:** واجهة لعبة — سلّم/برج تصعد فيه شخصيتك مع كل ترقية، متطلبات مرئية،
  واحتفال عند النجاح.
- **المتجر والعملات:** اكسب العملات من التقييمات والمهام والترقيات، وأنفقها على إطارات الصورة
  وشحن الطاقة.
- **شخصيات الزملاء بالذكاء الاصطناعي:** من «الهيكل التنظيمي» يمكن توليد صورة بكسلية لأي زميل من صورة
  (عبر دالة Vercel + مفتاح OPENAI_API_KEY)، وتظهر في الهيكل وفي صندوق الحوار.
- **خريطة مصغّرة للجوال** + **تمرير (swipe) للتنقّل في المقدّمة**.
- **محرّك صوت** مُولّد ذاتيًا (مؤثرات + موسيقى هادئة) مع كتم.
- **تصميم داخلي لكل مبنى:** مشهد داخلي متحرّك بطابع كل مبنى يظهر عند الدخول إلى أيٍّ من المحطّات.
- **تقدّم متعدّد المناطق:** أحياء تُفتح تباعًا مع ارتفاع المستوى (حي البداية → حي الفريق → حي القيادة)،
  مع أقفال مرئية على المباني المغلقة، لوحة «المناطق»، واحتفال عند فتح حيٍّ جديد.
- **حركات تفاعل أغنى مع المباني:** تكبير العلامة عند الاقتراب + ومضة وتموّج عند الدخول.
- **تدرّج لوني بهوية باور** فوق العالم لانسجام بصري مع العلامة.

## البنية التقنية

| المجال | الأداة |
|---|---|
| البناء | Vite + React 18 + TypeScript |
| التنسيق | Tailwind CSS (مدفوع بمتغيّرات هوية باور في `src/styles/tokens.css`) |
| عالم البكسل | Phaser 3 (محمّل ككتلة منفصلة كسولة) |
| الحركات | Framer Motion + canvas-confetti |
| الحالة | Zustand مع حفظ في `localStorage` |

### الجسر بين Phaser و React

`src/game/EventBus.ts` هو نقطة الوصل الوحيدة. يُصدر العالم أحداث الاقتراب/الدخول من المحطّات، ويستجيب React بفتح اللوحات وإيقاف حركة العالم مؤقتًا. تُدار كل المنطق والبيانات في React + Zustand؛ ويُستخدم Phaser للعرض والتنقّل فقط (لا نصوص عربية داخل اللوحة الرسومية).

## تخصيص الشخصية بالذكاء الاصطناعي (photo → pixel)

من زر **«الشخصية»** أعلى الشاشة:
- **توليد بالذكاء الاصطناعي:** ارفع صورتك ليحوّلها نموذج توليد الصور إلى شخصية بكسلية
  (كما في الدليل). تعمل هذه الميزة عبر دالة Vercel (`api/generate-character.ts`)
  وتتطلّب مفتاح `OPENAI_API_KEY` في إعدادات بيئة Vercel. الصورة الناتجة تُستخدم كأفاتار
  اللاعب في الواجهة ولوحة الصدارة.
- **ألوان الشخصية:** اختر لونًا لشخصيتك داخل العالم (يعمل فورًا دون مفتاح).

> ملاحظة: توليد الصور لا يعمل من بيئة التطوير المعزولة (محجوب)، لكنه يعمل في الإنتاج على
> Vercel بعد إضافة المفتاح. حتى ذلك الحين تتوفّر شخصية افتراضية وخيار الألوان.

## الخلفية (Supabase) — متعدّد المستخدمين

عند ضبط متغيّرات البيئة، يتحوّل التطبيق من نسخة فردية محلية إلى منصّة متعدّدة المستخدمين:
- **تسجيل/دخول** بالبريد وكلمة المرور (تسجيل مقيّد بنطاق الشركة عبر `app_settings.allowed_domains`).
- **أدوار:** موظف / مدير / موارد بشرية، مع لوحات مخصّصة لكل دور (RLS كامل على كل الجداول).
- **مزامنة التقدّم** لكل مستخدم في Supabase (مصدر الحقيقة)؛ `localStorage` كذاكرة مؤقتة.
- **إسناد المدير** للتقييمات والمهام لأعضاء فريقه + **إشعارات** فورية وعند الدخول.
- **السفارة:** طلبات إجازة/أسئلة مع تدفّق موافقة وإشعار بالنتيجة.

متغيّرات البيئة المطلوبة (محليًا في `.env` وفي Vercel):
```
VITE_SUPABASE_URL=...        # رابط مشروع Supabase
VITE_SUPABASE_ANON_KEY=...   # المفتاح العام (publishable)
```
> لتعديل نطاقات البريد المسموح بها أو المسؤول الأول: عدّل صفّ `app_settings` في قاعدة البيانات.
> بدون هذه المتغيّرات يعمل التطبيق كنسخة فردية محلية (StartScreen + حفظ محلي).

## النشر على Vercel

المشروع SPA من Vite. إعدادات `vercel.json` جاهزة (إطار `vite`، إعادة توجيه SPA، وتخزين مؤقت طويل للخطوط والأصول). اربط المستودع بـ Vercel أو استخدم `vercel deploy`.

## ملاحظات

- جميع الأرقام تُعرض بالأرقام العربية الغربية (0–9) وفق دليل الهوية، عبر المكوّن `NumberText`.
- زر «إعادة ضبط» أعلى الشاشة (على الحاسوب) يمسح التقدّم لتجربة كل الوحدات من جديد.
- الصوت (موسيقى/مؤثرات) غير مفعّل في هذه النسخة (مرحلة لاحقة اختيارية).
